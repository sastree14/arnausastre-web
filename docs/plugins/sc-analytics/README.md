# SC-Analytics plugin v1.4.0 — Commercial Acquisition

This source bundle expands the operating skills for cross-channel acquisition without asking Arnau to enumerate every possible search lane.

Canonical acquisition routes: direct operational clients, LinkedIn freelance/B2B openings and historical freelance recruiters, hiring alternatives, referral partners, technical complementary partners, delivery partners, agencies/staffing firms, Upwork, other marketplaces, RFP/supplier programs, growth/finance signals, and previously researched uncontacted businesses.

The new `skills/opportunity-scout/references/acquisition-taxonomy-and-playbooks.md` defines the protected/NDA-source exclusion, source-backed qualification, contact-channel decision tree, recruiter-versus-buyer handling, individualized phone/email/LinkedIn scripts and 30-minute discovery CTA. Read with commercial-operating-policy.md and cmi-runtime-contract.md.

The CMI Clients and Partners view uses the preexisting company relationship_type enums plus LinkedIn B2B/freelance as a linked-opportunity SOURCE facet. It shows verified public contacts, notes, approach recommendations, call scripts and status. No new scheduled tasks or auto-outreach.

Release caveat: editing the GitHub source bundle does not automatically replace an installed ChatGPT plugin. Package/reinstall this exact version when ready. The existing SC-Analytics app ID, permissions and logo must be preserved. The skill bundle cannot invent LinkedIn apply/message API capabilities absent from the connected runtime.
