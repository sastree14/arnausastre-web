# SC-Analytics plugin V1

The plugin is intentionally small. It packages repeatable operating workflows and relies on connected apps/tools for live data and actions.

## V1 skills

- editorial-operator
- performance-analyst
- commercial-research

## Design rule

Add a new skill only after the workflow has been used repeatedly and benefits from a stable procedure.

Add a custom MCP server/tool only when existing connected apps cannot reliably perform the required read/write action or when several low-level operations should be encapsulated behind one safe business action.

The CRM is the system of record and review surface. ChatGPT/Work is the interaction surface.
