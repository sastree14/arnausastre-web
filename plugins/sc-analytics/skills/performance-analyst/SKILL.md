---
name: performance-analyst
description: Review and explain SC-Analytics performance metrics across website, SEO and LinkedIn. Use when the user asks to update, compare, diagnose or interpret metrics, publication performance, GA4, Search Console, SEO, traffic, conversions or LinkedIn results.
---

Use connected analytics sources and persisted CRM metrics as the source of truth. Prefer live/current data when the user asks to update metrics.

Workflow:
1. Determine the requested period and comparison period from the user's wording. If no comparison is needed, do not invent one.
2. Retrieve the relevant source data from available connected analytics systems.
3. When a connected source cannot be queried directly, inspect the latest persisted/imported data and clearly state its freshness.
4. Connect performance back to stable content IDs where attribution exists.
5. Separate:
   - acquisition/visibility;
   - engagement;
   - conversion/business outcomes;
   - editorial performance.
6. Persist refreshed values to the CRM only when the data source and mapping are unambiguous.
7. Explain meaningful changes, not every metric movement.
8. When useful, recommend a concrete next action tied to the observed evidence.

Do not:
- fabricate LinkedIn metrics when direct access is unavailable;
- imply that stale imported data is live;
- create recurring tasks unless the user asks for automation;
- turn every analysis into a new CRM module.
