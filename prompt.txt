Quiero crear un sistema manual y estructurado para Projects.

No quiero automatización con Gemini para Projects.

Objetivo:
Yo subiré manualmente una carpeta por proyecto con:

* un archivo project.txt
* una imagen sin fondo, normalmente cover.png o cover.svg

La web debe leer esos archivos y construir automáticamente:

1. La página /projects con tarjetas de proyectos.
2. Cada página individual /projects/{slug}.

Estructura deseada:

content/projects/
ecommerce-forecasting-inventory/
project.txt

public/projects/
ecommerce-forecasting-inventory/
cover.png

Forecasting, Simulation, Inventory Optimization

Challenge:
Demand Planning

Short public description of the project.

* ASINs: 2,100+
* Simulations: 250 scenarios

Image:
cover.png

Published

Sections:
Context:
...

Problem:
...

...

...

Results:
...

Confidentiality:
Client name, internal data and operational details anonymized.

Requirements:

* Create a parser that reads every content/projects/{slug}/project.txt.
* Extract Headline, Industry, Capability, Challenge, Description, Metrics, Image, Status and Sections.
* Only show projects with Status: Published.
* The image path should resolve automatically to /projects/{slug}/{image}.
* Images may have transparent background, so display them inside a sober SC-Analytics card/background.
* Do not modify the images themselves.
* The design must be classic, sober, professional, blue/white, consistent with SC-Analytics.
* /projects should show square or rectangular cards with:

  * image
  * headline
  * industry
  * capability
  * short description
  * 3 to 5 metric boxes
* On click, open /projects/{slug}.
* The project detail page should show:

  * Hero with headline and image
  * Industry / Capability / Challenge
  * Description
  * Metric boxes
  * Sections from project.txt
  * Confidentiality note
  * CTA to Contact

Important:

* Projects are curated manually.
* No Gemini.
* No Google Sheet dependency.
* No automatic generation.
* No private code, datasets, client names or sensitive information should be exposed.
* The system should be scalable to 20–30 projects, but optimized for quality over quantity.
